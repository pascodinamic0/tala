# Tala — Marché de Kinshasa

PWA marketplace française-first : immobilier, véhicules, annonces.
Listings gratuits + boosts / forfaits agents. **Aucune commission sur la vente.**

## Stack

Next.js App Router · TypeScript · Tailwind · Dexie · installable PWA

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
```
